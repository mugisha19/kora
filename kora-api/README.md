# Kora API

Spring Boot back end for **Kora**, a multi-tenant project & portfolio management platform built on PMI
practices (Agile, Predictive, Hybrid).

> 🚧 In active development: see [`docs/PROGRESS.md`](docs/PROGRESS.md).

## Tech

Java 25 · Spring Boot 4.1 · Spring Modulith (modular monolith, hexagonal modules) · PostgreSQL 18 + Flyway ·
Testcontainers · ArchUnit · JaCoCo · Spotless + Checkstyle · GitHub Actions + GitLab CI

## Run locally

Requires JDK 25 and Docker (for PostgreSQL and the integration tests). Maven comes with the wrapper.

```bash
cd kora-api
./mvnw spring-boot:run   # starts compose.yaml services, then the API on http://localhost:8080
./mvnw test              # fast unit and architecture tests
./mvnw verify            # everything CI runs: format, static checks, unit + integration tests, coverage
./mvnw spotless:apply    # fix formatting
```

Health: `GET /actuator/health` · build info: `GET /actuator/info` · metrics: `GET /actuator/prometheus`

Without Docker, `./mvnw verify` still runs everything except the integration tests, which are reported as
skipped (in CI they fail instead, so a broken runner can't pass).
